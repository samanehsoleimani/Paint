# پروژه Paint شخصی

این پروژه یک نرم‌افزار نقاشی (Paint) کاربردی است که با هدف درک عمیق مفاهیم گرافیکی و توسعه یافته است.

## ویژگی‌های فنی
* **پیاده‌سازی صددرصد دستی (Custom Implementation):** تمامی ابزارها، مدیریت رنگ‌ها و منطق رسم، بدون استفاده از کتابخانه‌های جانبی یا کلاس‌های آماده نوشته شده‌اند.
* **تمرکز بر شی‌گرایی (OOP):** ساختار پروژه به‌صورت کامل بر اساس اصول شی‌گرایی طراحی شده است تا تعامل بین ابزارها، بوم (Canvas) و سیستم مدیریت رویدادها به‌صورت کاملاً ماژولار و قابل توسعه باشد.
* **هدف آموزشی:** این پروژه با راهنمایی‌های [غلامعلی نژاد حاجعلی ایرانی] و با هدف تسلط بر منطق برنامه‌نویسی و اصول OOP در سطح نرم‌افزارهای گرافیکی انجام شده است.

## ابزارهای پیاده‌سازی شده
* **مداد (Pencil):** رسم آزاد با بهره‌گیری از کلاس‌های مدیریت رویداد موس.
* **انتخاب رنگ (Color Picker):** سیستم اختصاصی برای مدیریت و انتخاب رنگ‌های پویا.

## ساختار شی‌گرا
این برنامه از الگوهای طراحی (Design Patterns) برای جداسازی مسئولیت‌ها استفاده می‌کند:
- استفاده از کلاس‌های انتزاعی (Abstract Classes) یا اینترفیس‌ها برای تعریف ابزارها.
- کپسوله‌سازی (Encapsulation) برای محافظت از داده‌های مربوط به بوم نقاشی.
- پلی‌مورفیسم (Polymorphism) در پیاده‌سازی رفتار ابزارهای مختلف.

## نحوه اجرا
برای اجرای پروژه، کافی است متد اصلی (`Main`) را در محیط توسعه (IDE) خود اجرا کنید.
